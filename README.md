## How it works

`main.ts` (Node 22, TypeScript run as-is) validates the word — a single
word, 1–111 characters, printable ASCII letters only — writes it to
`/output/entry.txt`, then reads the file back and verifies it byte-for-byte.

```sh
node main.ts
cat /output/entry.txt
```
